# AE-DT fatigue prediction for DD6 single-crystal superalloys

This repository contains the datasets and Python codes supporting the study:

"Acoustic-emission damage trajectories enable fatigue-life prediction in Ni-based single-crystal superalloys"

The repository includes:
- fatigue datasets of DD6 single-crystal superalloys
- literature-based fatigue records
- machine-learning models and validation codes
